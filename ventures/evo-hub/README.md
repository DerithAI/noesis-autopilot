| System | Role | Port |

## 🚀 Quick Start

### 1. Start LUMEN OS
```bash
cd C:\Users\Main\SELF-EVOLVING-SYSTEM\m-ai-self
.venv\Scripts\python.exe -m uvicorn apps.api.main:app --port 8002 --host 0.0.0.0
```

### 2. Start EVO-HUB Backend
```bash
cd ventures/evo-hub/backend
EVO_HUB_PORT=8003 python -m uvicorn main:app --host 127.0.0.1 --port 8003
```
> Port is configurable via `EVO_HUB_PORT` (default 8000). Note: LUMEN
> MEGA-PLATFORM occupies :8000, so use 8003 unless that's free.

### 3. Start EVO-HUB Frontend
```bash
cd ventures/evo-hub/frontend
npm install
npm run dev            # http://127.0.0.1:5173
```
> Vite proxies /health, /agents/status, /cognitive/loop, /memory/search
> to the backend on :8003.

### 4. Run Tests
```bash
cd ventures/evo-hub
EVO_HUB_PORT=8003 python -m pytest tests/ -q
```

### 5. One-Shot Stack Status
```bash
cd ventures/evo-hub
python status.py          # human-readable
python status.py --json   # machine-readable
python status.py --watch 5
```

## ⚙️ Operational Notes

- **LUMEN event loop**: since the OllamaProvider AsyncClient fix, `/health`
  answers during long `/process` LLM calls. A `/process` round-trip can take
  20–90s (local 2GB model); tests skip gracefully when LUMEN is mid-call.
- **Episodic endpoint**: `/api/memory/episodic` is paginated (`limit`,
  default 100, `offset`) — the store has 90k+ JSON files.
- **Semantic search**: keyword fallback threshold fixed to 0.1; search
  returns real memories for common terms (e.g. `chat`).
- **Tests**: integration tests hit the live LUMEN; they skip (not fail)
  when LUMEN is busy — a skipped test is availability, not a bug.
